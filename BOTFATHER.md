# BotFather Setup Guide

Copy and paste these blocks directly to [@BotFather](https://t.me/BotFather) on Telegram to configure your bot profile!

---

## 1. Set Commands (`/setcommands`)

```text
start - Start the bot & view main menu
help - Open command grimoire & help categories
info - View user details & profile pic count
id - Quick user & chat ID info
rules - View group rules
setrules - Set group rules (Admin)
adminlist - List chat admins
settings - Open interactive settings dashboard (Admin)
pin - Pin replied message (Admin)
unpin - Unpin message (Admin)
unpinall - Unpin all messages (Admin)
permapin - Bot sends and pins message (Admin)
antichannelpin - Toggle auto-unpinning channel posts (Admin)
ban - Ban a user (Admin)
unban - Unban a user (Admin)
tban - Temp ban user with duration e.g. 1h30m (Admin)
kick - Kick a user (Admin)
mute - Mute a user (Admin)
unmute - Unmute a user (Admin)
tmute - Temp mute user with duration e.g. 1h30m (Admin)
warn - Warn a user (Admin)
warns - Check user's warnings
unwarn - Remove last warning (Admin)
resetwarns - Clear user warnings (Admin)
setwarnlimit - Set warn limit (Admin)
setwarnmode - Action on max warns (Admin)
setflood - Set antiflood limit (Admin)
setfloodmode - Set antiflood action (Admin)
addblacklist - Blacklist a word (Admin)
rmblacklist - Remove word from blacklist (Admin)
blacklist - List blacklisted words
blocklistmode - Action on blacklisted word (Admin)
blacklistdelete - Toggle auto-delete blacklisted msgs (Admin)
save - Save a note (#note_name trigger) (Admin)
get - Retrieve a note
notes - List chat notes
clear - Delete a note (Admin)
clearall - Clear all notes (Admin)
filter - Add auto-reply filter (Admin)
filters - List chat filters
stop - Remove a filter (Admin)
stopall - Remove all filters (Admin)
lock - Lock media/content type (Admin)
unlock - Unlock media/content type (Admin)
locks - Show active locks
locktypes - List supported lock types
approve - Approve user from restrictions (Admin)
unapprove - Remove user approval (Admin)
approved - List approved users
logchannel - View log channel
setlog - Set action log channel (Admin)
unsetlog - Unset log channel (Admin)
report - Report message to admins
reports - Toggle user reports (Admin)
captcha - Toggle member captcha (Admin)
captchamode - Set captcha mode (button/math/text) (Admin)
setcaptchatime - Set captcha timeout seconds (Admin)
antiraid - Toggle anti-raid mode (Admin)
raidtime - Set anti-raid duration (Admin)
raidactionmode - Set anti-raid action (Admin)
disable - Disable a command for non-admins (Admin)
enable - Re-enable a command (Admin)
disabled - List disabled commands
enableall - Enable all commands (Admin)
connect - Connect to chat in PM (Admin)
disconnect - Disconnect active PM connection
connection - Check active connection
newfed - Create a federation
delfed - Delete a federation
joinfed - Join chat to federation (Admin)
leavefed - Leave federation (Admin)
fban - Fedban user across federation
unfban - Un-fedban user
fedinfo - View federation details
fedadmins - List federation admins
fedpromote - Promote federation admin
feddemote - Demote federation admin
purge - Delete range of messages (Admin)
del - Delete replied message (Admin)
roll - Roll a dice
8ball - Magic 8-Ball answer
quote - Get an anime quote
ship - Ship two chat users
power - Measure anime power level
support - Official support & community
donate - Support bot development
```

## 2. Short Description (`/setshortdescription`)

```text
An anime-themed Telegram group management bot. Features moderation, warnings, antiflood, antispam, captcha, anti-raid, notes, filters, locks, action logs, and federations.
```
